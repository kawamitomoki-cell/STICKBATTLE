## 調査

旧AIは `10-cpu-ai.js` の距離分岐と多数のMath.randomで選択。最高難易度はthink=2、read=.98、spec=.41。近距離の通常/溜め/防御や固有技に複数の確率判定があり、乱数次第で有効技を見送る。位置はfightersから直接取得し、速度・技硬直を攻撃選択にほぼ利用しない。正常攻撃にカウンターを選ぶ分岐も三すくみに合わない。足場経由・崖停止・復帰の既存ヘルパーは利用価値がある。

技はMOVE_DEFとANIME_MOVESにact0（発生）、act1（持続終了）、end（硬直終了）、cd、reach、R、yo等。例：通常4/8/14、斧24/28/88。実ダメージ等はfireAttackや固有技関数が補正する。meleeCheckは円または線分、飛び道具は独立更新。stepFighterは共通入力のカウンタ差分で技を開始する。CPUにも同じ入力、ゲージ、クールダウン、物理、被弾が適用される。1～7 CPUと分身はsimulateFrameから毎シミュレーションフレームaiStepを呼ぶ。

## 初期実装

- 小さなUtility AIと既存ナビゲーションの組合せ。Behavior Treeや探索木は導入しない。
- 公開状態だけを最大25サンプルのキューに保持。難易度別に24/18/12/8フレーム遅れた敵の位置、速度、技、空中/被弾/無敵等を読む。入力情報を参照しない。
- 判断周期12/9/6/4フレーム。ホールド/入力解除と自分の復帰は別処理。停止・領域中は新しい判断をしない。
- 通常、溜め、特殊を候補として有限個評価。速度と重力による短い位置予測、届く距離、発生、ダメージ、敵の硬直、無敵、ダメージ量、被弾中の追撃、攻撃を受けるリスクを点数化。
- 候補内の小さな揺らぎ、直前行動の減点、失敗余地を難易度で変更。回避・カウンター傾向を短期平均し、待ちを10フレームに制限したフェイントを追加。
- 遅延観測した大技にカウンター、通常技には回避。飛び道具は危険物が反応時間以上見えてから防御。空中の近い敵には既存の攻撃判定付き上特殊を選ぶ。
- 遠距離キャラの間合い、敵の被弾中の接近、既存足場移動と復帰を維持。上特殊で上昇しない弓/狂戦士には復帰として使用しない。
- AI_CHARACTER_PLANは17体の間合い設定。AI_SKILLSは17体の特殊入力・推定性能・使用条件。ナルトの2体分身、変身、時止め、領域、リロードは小さな能力アダプタで条件を設定。
- 戦闘・操作・通信・演出のコードは変更していない。旧AIの確率的special selectorは削除。

## テスト・測定

`npm run build`、`npm run check`、`npm test`成功。62件成功、失敗0、スキップ0。
分身の追尾テストは即時反応を仮定していたため、観測遅延を待ち、保持中ボタン値ではなく押下エッジで攻撃開始を確認するよう更新。
追加テストは反応時間、バッファ上限、硬直反撃の点数、無敵拒否、離れる敵の予測、難易度差、三すくみ、防御、17体アダプタ、復帰、分身入力を対象とする。

`node scripts/benchmarks/cpu.mjs`で再現可能。旧ソースはcpu-v27.txtに保持。シード1～3、各1800フレーム、選択キャラ対格闘家、両者を同じ版のAIで操作。撃墜後は復活させ継続。結果はresults.txt。

|格闘家対格闘家|546.2→656|55→76|11→10|

値は両陣営の合計。勝率や新旧直接対決の強さを意味しない。hitEventsには飛び道具/多段を含み、attacksはfireAttack呼出しのみなので、その比を命中率にしてはいけない。死亡数は自滅と被撃墜を区別していない。

負荷試験は1/3/7 CPUを1200フレーム動かし、aiStep時間のみ約8.1/21.6/56.3ms（各フレーム約.007/.018/.047ms）。CPU別の移動も実行するが、描画・通信・衝突等の総時間ではない。機器依存の参考値で、スマホFPSを保証しない。

## 残課題・次段階

本改修は共通AIの初期段階。上級者相当の強さ・面白さを達成したと断定しない。
- 攻撃候補は通常/溜め/代表特殊。特殊性能は推定値であり、全方向技・フォーム・武器補正を厳密に列挙していない。溜めと通常も固有技補正の完全再現ではない。次段階で実技データに基づく副作用なしの共通メタデータへ集約する。
- 悟空のビーム/瞬間移動、専用コンボ、命中イベントを起点とする連係、厳密な撃墜予測、残機差に応じた戦略は未実装。現状の追撃は遅延観測したkbを利用するだけ。
- 足場探索は既存のまま。弓/狂戦士の自滅率や全ステージの復帰成功率、飛び道具反応の最適化は未測定。
- 真の攻撃命中率・空振り率・反撃成功率・自滅率・復帰率・キャラ別勝率、プレイヤーとの対戦評価は未測定。狂戦士の与ダメージ低下は特に要調整。
- オンライン実通信、スマホ/ゲームパッド実機、描画込み性能は未検証。公開しない。
- 観測は各CPUから最寄り敵を走査するO(N)。判断候補は定数個、観測キューも上限あり。ただし毎フレームの小さな観測オブジェクト生成があるため、必要ならリングバッファと共有観測へ改善する。

次の優先は新旧直接対決と攻撃ごとの成否計測を追加し、狂戦士を含むキャラ別バランス調整、実プレイヤーの読み合い評価。共通AIを基に能力アダプタを拡張する。新キャラもAI_SKILLSとAI_CHARACTER_PLANに定義すれば代表特殊と共通操作へ対応できるが、固有能力は専用フックが必要。
