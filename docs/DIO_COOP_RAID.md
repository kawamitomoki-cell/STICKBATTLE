# 協力ボスバトル：DIO

最大4人でDIOのHPを削る独立モード。通常の対戦・トレーニング・組み手・トーナメントは従来の％と残機ルールを使う。DIOは選択可能キャラの一覧には追加しない。

## 遊び方と編成

モード選択 → 「協力ボスバトル」。説明画面からオンラインの部屋作成・参加、またはソロのキャラ選択へ進む。

- ソロは自分＋味方CPU 0〜3人。各CPUのキャラを個別に選べる。ランダムも可。専用編成の初期値は承太郎・五条・金木。通常CPU戦の設定とは別に保持する。
- オンラインは人間とCPUの合計4人まで。ホストが空き枠のCPU人数・キャラを設定する。CPUはホストで実行する。人が増えたら開始時にCPUを減らす。
- CPUは最強固定。通常の入力・攻撃・移動性能で戦い、ボス専用の予兆への対処を優先する。承太郎CPUは時止め返し後にDIOへ接近し、通常のオラオララッシュで中断を狙う。
- 味方同士の攻撃は当たらない。戦闘中はキャラを変更できない。リザルトから編成に戻れる。
- 編成はページ内で保持する。リロード後には初期値へ戻る。

## ルール

| 項目 | 内容 |
| --- | --- |
| ボスHP | 6,400。人数による弱体化なし |
| 制限時間 | 戦闘中の300秒。カウントダウン・演出による全体停止中は消費しない |
| プレイヤー | HP 240、残機2。復帰時にHP回復、従来のキャラゲージ初期化を使用 |
| 勝利 | DIOのHPが0 |
| 敗北 | 全員脱落、または時間切れ |
| アリーナ | カイロ専用の閉じた床と上段足場。通常の10ステージの候補には追加しない |
| 特殊な耐性 | DIOは場外撃墜・捕縛・強制KO無効。即撃墜技もHPダメージとして処理 |

## 時止め返し：承太郎だけの反撃

1. DIOが100フレームの予告後に時間を停止する。
2. 停止後120フレーム以内に承太郎が下＋特殊（スマホの下技）を押す。通常の時止めゲージは不要。停止前のクールダウン・のけぞりも解除する。
3. **止め返した承太郎だけが動いて反撃できる。** 仲間は停止したまま。別の承太郎も、自分で止め返すまでは停止する。DIOの停止は240フレーム続く。
4. 反撃で64 HP分（後半は83.2）を削ると、停止終了時の大技を中断できる。画面に中断までの残りゲージを表示する。
5. 中断が成功しても仲間は停止終了まで動けない。再開後150フレームは全員の与ダメージが1.65倍。
6. 中断失敗は全体185ダメージ、後半285ダメージ。無敵・無下限・通常の鎧では防げない。編成説明に承太郎不在の警告を表示する。

承太郎以外の攻撃、停止前に出した飛び道具、分身も停止中にボスHPを削れない。操作の停止だけでなく、ホストのダメージ確定時にも検証する。

## ボス専用の攻撃

- **投げナイフ：** 高さを予告して複数回の斉射。五条は無下限で防げる。他のキャラはジャンプ・回避。後半は斉射数・ダメージが増える。
- **無駄無駄ラッシュ：** 正面に連続打撃、最後に重い打撃。背後へ移動して避ける。近距離への攻撃予兆とスタンドの拳を描く。
- **ロードローラー：** 狙った場所を予告して落下。その後に床全体の衝撃波。後半は衝撃波が2回。着地点から離れてジャンプで避ける。
- **突進：** 狙った位置までの軌道を予告し、高速で横断する。
- **ザ・ワールド：** 時計、止まったナイフの包囲、ロードローラーによる専用連携。反撃の可否は上記の承太郎ルールに従う。

HP50%以下で後半へ移る。DIOとザ・ワールドは専用の静的形状と攻撃ポーズで描画する。外部画像や常時増殖するエフェクトは使わない。

通常の防御特性は一般攻撃に有効。狂戦士の鎧・エレンの硬質化はHPダメージを軽減する。金木の自己再生は3回の命中確認で4 HP、6秒間隔、1残機あたり最大40 HP。五条の領域・承太郎の通常時止めはボスに短い隙を作る（制御効果の共有クールダウン18秒）。ボスを永久に拘束できない。

## 同期と実装

- `src/game/17-boss-raid.js` にボス進行、HP、味方CPU、画面、同期の追加を集約。メインループに専用進行を1回追加。
- ボスHP・攻撃順・進行フレーム・中断ゲージの確定はホストのみ。ボスの既存スナップショットへ小さな `raid` 状態を追加し、毎フレームの追加DB書き込みは行わない。
- ボス攻撃はホストイベント。被弾側が自分のHPだけを更新し、既存のラウンド番号とUID重複排除を通す。
- 止め返し要求は所有者・キャラ・生存・対象攻撃番号・受付時間をホストで確認。承認後のスナップショットで操作権のある端末もクールダウン解除を行う。
- プロトコル `SBO_NET_DIO_RAID_V45`。全員が更新し、新しい部屋で遊ぶ必要がある。
- 人間プレイヤーのHP・残機は既存対戦と同じく各端末が所有する。専用サーバーによる不正対策を提供する方式ではない。

## 検証

`npm run build` / `npm run check` / `npm test`（209件成功）。ボス専用のテストでは編成、HP、時止めのキャラ制限、中断、CPU承太郎、後半の大技、鎧、ストック、時間切れ、2つの独立VM間でのHP同期・重複イベント・偽の要求を検証する。

ブラウザー確認スクリプト：

- `scripts/benchmarks/raid-browser.cjs`：1440×1000、390×844、320×740、844×390。説明→個別CPU選択→出撃→停止→反撃、横にはみ出さないこと、描画エラーを確認。
- `scripts/benchmarks/raid-network-browser.cjs`：Chromium 2ページとメモリー内の部屋アダプターで、ロビー開始→ゲスト承太郎の実キー入力→ホストの中断承認→攻撃・HP同期を確認。本番Firebaseへの書き込みはしない。

難易度は初期調整値。実プレイヤー4人でのクリア率・実回線の通信遅延を含む長時間プレイの調整は別途必要。
