# DIO：みんなで倒す最強NPC

DIOは承太郎と同じ通常サイズのNPC。通常のステージで動き回り、追跡・ジャンプ・回避・復帰・技の連携で戦う。最大4人でDIOのHPを削って倒す。

## 今回の修正

以前の大型・固定ギミック型ボスから、普通の対戦キャラと戦う方式へ変更した。

- 味方は**普段と同じダメージ％・吹っ飛ばし・残機2**。HPは持たない。％が高くなっても自動で死亡せず、場外で残機を失う。
- HP制なのはDIOだけ（6,400）。人数で弱体化しない。全員脱落で敗北、DIOのHPが0で勝利。制限時間なし。
- DIOの当たり判定は通常サイズ1。描画も普通のキャラと同程度。ザ・ワールドは技や時止め中に現れる。
- 攻撃範囲の色付き床、着地点マーカー、次の技の予告、反撃ゲージ、全員への確定ダメージ、時止め返し後の倍率を撤去。
- ステージは通常のひろびろ平原。味方の横移動をクランプしない。場外撃墜・ジャンプ・復帰は普段のルール。

## 遊び方

モード選択 → 「協力ボスバトル」。オンラインの部屋作成・参加、または「ソロ・味方CPUと挑む」へ進む。

ソロは自分＋味方CPU 0〜3人。各CPUのキャラを個別指定でき、ランダムも選べる。初期編成は承太郎・五条・金木。オンラインも人間と味方CPUを合わせて4人まで。人間が増えれば開始時にCPU枠を減らす。

通常CPU戦・トレーニングの相手設定とは別に保持する。編成はページ内で保持し、リロードで初期化する。味方同士の攻撃は無効。試合中のキャラ変更は不可。

## NPCの戦い方

| 技・行動 | 挙動 |
| --- | --- |
| 追跡・回避 | 短い思考間隔で間合いを詰める。ジャンプ・足場降り・回避・背後への瞬間移動も使う |
| 近接 | 素早い打撃、踏み込み蹴り、無駄無駄ラッシュ。ラッシュの最後は吹っ飛ばす |
| 投げナイフ | DIOの位置から実体のある複数の飛び道具を発射。範囲一括ダメージではない |
| ロードローラー | 空中から実体を投げ落とす。重力で落ち、接触した相手を吹っ飛ばす |
| 復帰 | 通常の重力・ジャンプ・復帰技を使用。DIOはHP制なので場外では再登場し、HPは減らず回復もしない |
| HP半分以下 | 動作判断・再使用間隔・ナイフ数・攻撃力がさらに強化される |

DIOにも被弾の動きと吹っ飛びがある。ノックバックはボス向けに抑え、HPが残る間は即撃墜の技だけで勝利できない。通常カウンターで返したダメージもDIOのHPへ反映する。

## 時止め

DIOは自分のタイミングで「ザ・ワールド」を発動し、停止中も移動・攻撃できる。味方の動作と飛び道具は停止する。ダメージ・吹っ飛ばしは既存の時止めキューで時間再開時に反映する。

**止め返して動けるのは承太郎だけ。** 停止中に下＋特殊（スマホの下技）を押すと、DIOとその飛び道具を止めて反撃できる。専用ゲージ削りや2秒の受付制限はない。通常の時止めゲージは不要。他の仲間は時が動き出すまで動けない。別の承太郎も、自分で止め返す必要がある。

承太郎CPUも止め返す。移動・足場越え・復帰には通常のCPU判断を使い、攻撃できる間合いでオラオララッシュを狙う。

五条の無下限、回避や無敵、金木の％再生など、味方の通常能力は既存の処理を使う。通常時の承太郎の時止め・五条の領域は味方を止めず、DIOへ短い拘束を与える。拘束には共有の再使用制限がある。

## 同期と検証

DIOの操作・AI・HP確定はホストが担当する。近接・飛び道具・被弾・％・残機には通常対戦の通信処理を使い、被弾側が自分の状態を更新する。ボスの既存スナップショットへ時止め状態を追加する。停止したキャラの移動予測も止める。

止め返し要求は所有者・キャラ・生存・停止番号を検証する。ラウンド番号とUIDの重複排除も継続。プロトコルは `SBO_NET_DIO_NPC_V46`。全員再読み込み・新規ルームが必要。

`npm run build`、`npm run check`、`npm test`（213件成功）。専用テストは、味方の％と2残機、場外撃墜、通常サイズ、移動・重力、攻撃の有効フレーム、実体のあるナイフ・ローラー、時止め返し、通常カウンター、味方CPU、2端末でのダメージ・停止解除・重複排除を検証する。

ブラウザー確認：`scripts/benchmarks/raid-browser.cjs`（PC・スマホ4サイズ）、`scripts/benchmarks/raid-network-browser.cjs`（2ページの実キー入力と同期）。ネットワーク検証の部屋はメモリー内アダプターで、本番Firebaseへ検証データを書き込まない。

実回線4人での長時間プレイと難易度調整は未検証。
