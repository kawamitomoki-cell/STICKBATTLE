# エレン：通常特殊を斬撃へ・横特殊の持続・覚醒の強化

- 人間の通常特殊はアンカー不要の双剣4連斬り（5×4）。地上で攻める独立した攻撃になった。
- 横特殊は前方の同じ高さの足場を優先して接続し、上に飛びすぎず地上へ切り込む。斬撃持続を13→30フレーム、複数回の斬撃に変更。初段14、中段14、終段20（すべて命中した場合）。全体44フレーム、特殊再使用56フレーム。heavy扱いでカウンター可能、連続中でも被弾でワイヤー解除される。
- ワイヤー継続上限42フレーム。アンカーの直前では速度を落とし、通過して崖へ飛び出す危険を抑える。接続できない場合もその場で連斬を行う。
- 巨人化直後の無敵を24→60フレームへ。18秒間ずっと無敵にはしない。攻撃中は普通の攻撃・弾でひるみにくいが、ダメージは受ける。重い攻撃・カウンター・足場外への落下は残る。掴みには攻撃中アーマーを付けない。
- 巨人の無敵中に身体を半透明にせず、金色のオーラで表示する。
- 独立した説明文中心の変身画面を撤去。ルフィや悟空等と同じ `paintAnimeFormCutin` の黒帯・斜めテロップ・Impact書体の形態名を使用。Erenのパレットと名前だけ追加し、他キャラの演出は変更しない。
- 変身開始→落雷/放射線→蒸気と巨人の出現→衝撃波→ATTACK TITAN。光刺激抑制では共通描画のフラッシュも省く。形態時間は演出中消費しない。
- CPUの中距離接近を横特殊へ変更し、通常特殊は近距離の連斬として評価。人間とCPUは同じ性能。

## 検証

`npm run build` / `npm run check` / `npm test`成功。95件成功、失敗0、スキップ0。
新規試験はアンカーなしの地上4連斬り、横特殊の地上アンカー・30フレーム持続・カウンター可能性、巨人攻撃中に普通の攻撃ではひるまずダメージを受け重攻撃では吹き飛ぶこと。既存の無敵終了試験も60フレームへ更新。

p5 1.9.0＋Chromiumのローカルページで通常特殊・横特殊・新しい覚醒画面を描画し、画面画像を確認。実行時エラー0。検証ページは外部Firebaseを使わないため、実オンライン検証とは区別する。

対17キャラ×2シードの既存模擬戦は28勝6敗・時間切れ0、変身11回。前版は20勝14敗。単一ステージ・少数シードのCPU試験であり、対人バランスの確定ではない。横特殊の複数ヒットやアーマーが強すぎないか、実対戦で引き続き確認する必要がある。
結果はeren-results.json、前版はeren-mobile-results.json。
