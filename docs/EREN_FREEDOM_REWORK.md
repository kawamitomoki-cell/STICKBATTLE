# エレン再設計：立体機動で攻め続け、巨人化で戦況を変える

2026-10-28。現在の操作仕様。EREN_IMPLEMENTATION / EREN_POLISH / EREN_MOBILE_COMBAT / EREN_ASSAULT_AWAKENING は改修履歴であり、変更箇所はこの文書を優先する。

## 問題と設計

従来の横特殊は同じ高さのアンカーへ一直線に進む技で、攻撃の終了まで次の移動へ移れなかった。巨人化後も、通常特殊は単体掴み、地上の下特殊は攻撃と移動を制限する硬質化だった。巨大な見た目に対して突進距離も小さかった。

人間は「ワイヤー張り替え → 操舵しながら斬る → 勢いを保って離脱 → 再接続」、巨人は「被弾からの変身 → 周囲を吹き飛ばす → 広域攻撃・突進で押し込む」という異なる操作体験にする。

## 現在の操作

| 状態 | 入力 | 動作 |
|---|---|---|
| 人間 | 通常特殊 | 地上でも使える双剣4連斬り |
| 人間 | 横特殊 | 実在する足場へ接続して飛行連斬。接続時に離陸 |
| 人間・飛行中 | 方向入力 | 上下左右へ操舵 |
| 人間・飛行中 | 再び横特殊 | 直前の斬撃をキャンセルして張り替え。8フレーム間隔、ガス消費あり |
| 人間・飛行中 | 攻撃ボタン | 連斬から自分のタイミングの移動斬りへ切り替え。長押しは従来どおり溜め |
| 人間・飛行中 | ジャンプ | ワイヤー離脱。ジャンプ回数を消費せず、短い上向き速度と慣性を得る |
| 人間 | 上特殊 | 上の足場への復帰。空中1回 |
| 人間・ゲージMAX | 下特殊 | 被弾・硬直中も変身。時止め・領域による行動拘束中は不可 |

| 巨人・地上 | 下特殊 | 前後の敵を巻き込む地砕き |

| 巨人 | カウンター | 既存のカウンターに36フレームの硬質化を併用。再発動間隔180フレーム |

PCでは横＋K、W＋K、S＋K。スマホの通常特殊はスティック方向と独立した双剣連斬、横技ボタンは向いている方向への飛行連斬。ジャンプボタンで離脱する。

ガスは上限100、接続14、接続維持0.16/フレーム。空中斬撃命中で同じ振り・同じ相手につき6回収し、多段ヒットや重複通信では繰り返し増えない。地上2.5/フレーム、空中0.08/フレーム回復。ガス残量はHUDと人間の頭上の小さいバーへ表示する。着地補充と攻撃による回収で次の機動につなぐ。

ワイヤーは最長48フレーム。接続先に到達しても急停止しない。離脱後18フレームは空中操舵を強め、方向を離すと減速する。端での張り替え候補は「直前の攻撃の向き」ではなく「新しく入力した向き」で検索する。

## 巨人の手応えと外見

- 変身時に被弾硬直と掴みを解除。半径190内へ16ダメージの衝撃波を一度発生させる。味方・無敵・通常の防御処理を尊重する。
- 変身演出中は18秒の形態時間を消費しない。演出後90フレームの無敵。18秒全体の無敵ではない。
- 巨人移動倍率0.98→1.15。突進は16の踏み込みとrushで移動を維持。通常特殊の再使用を64→34フレームへ。
- 薙ぎ払い・地砕きにも攻撃中のアーマーを適用。通常攻撃にはひるみにくいがダメージは受ける。重い近接攻撃・カウンター・落下は有効。
- 硬質化で攻撃種類や移動速度を制限していた仕様は廃止。防御を選んだ際の補助へ移す。
- 巨人の大技命中に衝撃リングと揺れ。オフラインでは1振りにつき1回、8フレームのヒットストップ。オンラインでは独自の全体停止を増やさない。
- 人間の分かれた前髪、茶の短ジャケット、白い脚衣とハーネス、翼章、緑のマント、両腰の装置、交差する双剣を戦闘画面・選択ポートレートで描き直した。飛行時は身体を傾け、2枚までの残像を描画。
- 巨人は長髪、耳、緑の目、広い肩と腕、蒸気で形態を区別。他のSPECIALキャラの簡略化した図形表現に合わせる。
- 既存の共通覚醒カットイン（黒帯・斜めの形態名）を維持し、再設計後の身体を表示する。
- 練習モードのゲージ補充ボタンとリセットの補充処理をErenにも対応。巨人化ボタンはMAXでREADY表示。
