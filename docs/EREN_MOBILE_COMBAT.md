# エレン：共通スティック調・立体機動戦闘

今回の指摘を優先し、独自の顔・歯・顎・筋肉の写実寄り表現を撤去した。選択画面と戦闘中とも、他のSPECIALキャラと同じ丸い顔・顔パーツなし・丸い手足・衣装と髪で区別する表現へ統一した。ポートレートの背後の巨人や複雑な構図も撤去し、他キャラと同じサイズ/配置にした。

## 人間の立体機動戦闘

- ワイヤー中の短押し通常攻撃は「移動3連斬り」（6×3）に切替。
- 斬撃の持続中はrush指定で移動時の減速を抑え、牽引と攻撃を同時に実行。
- ワイヤーの牽引上限15→23、加速2→3.1、射程340→440、持続26→32、再使用65→36フレーム。
- アンカーは実在する足場のみ。上特殊は空中1回、被弾で接続解除、多段のゲージ加算は1攻撃/対象につき1回を維持。
- CPUも中距離でワイヤー接近し、その途中に通常攻撃を使う。

## 巨人

- 通常移動係数.76→.98（通常キャラに近い速さ、エレン人間1.15より遅い）。
- 通常攻撃を左右2連打（9＋13）へ変更。発生6フレーム、終了24、CD5。
- 空中の下特殊に「踏みつけ」を追加。24ダメージ、落下速度14、着地衝撃波。空中1回、着地で回復。
- 地上の下特殊は従来の硬質化。上特殊のアッパー、横特殊のタックル、掴み、鉄拳は維持。
- CPUは頭上の敵にアッパー、空中から下の敵へ踏みつけを選択可能。

## 検証

`npm run build` / `npm run check` / `npm test`成功。92件成功、失敗0、スキップ0。
追加試験はワイヤー斬撃中の実移動と命中、3ヒット/ゲージ上限、巨人2連打、踏みつけの空中使用回数・地上硬質化との切替。10フレームで合計100px以上の立体移動中に命中することを確認。

ローカルp5 1.9.0＋Chromiumで、選択一覧と他のSPECIALキャラの横にエレンを表示して確認。人間、ワイヤー斬撃、巨人、踏みつけの描画で実行時エラー0。タッチ付き390px幅でも、特殊→攻撃の実タップでerenWireCutへ切り替わることを確認。これは外部Firebaseを使わないオフライン検証であり、実機や実通信の試験ではない。

対既存17キャラ×2固定シード、3残機、標準ステージ、3600フレーム上限の模擬戦は20勝14敗、変身19回。前の性能改修版は19勝15敗だった。勝率だけを改善目的にせず、今回は移動しながら戦う操作と見た目の統一を優先した。単一ステージ・少数シードで対人バランスは未確定。

通信プロトコルは `SBO_NET_EREN_MOBILE_V33`。全員再読み込みして新しい部屋を作る必要がある。実サービスでの掴み・ワイヤー・新攻撃の同期、複数ステージでのバランス、描画/通信込みのスマホ性能は引き続き未検証。
