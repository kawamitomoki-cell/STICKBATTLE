# エレン：描画と戦闘性能の改修

## フィードバックへの対応

立体機動が良いという評価を受け、地形アンカー選択・ワイヤー牽引・有効時間・射程・回数制限はそのまま維持した（旧ソースと該当関数の一致を確認）。描画とエレン固有の技だけを改修した。

### 戦闘中のデザイン

人間は短い革ジャケット、白いシャツ、クロスハーネス、留め具、ガス筒と射出装置、緑のマント、輪郭と反射面を持つ双剣に描き直した。肩/肘/手、腿/膝/脛を分け、陰影とハイライトを追加。
巨人は肩・胸筋・腹筋・骨盤を別形状にし、細い腰と太い腕を明確化。顎、歯、頬、目、長い髪、耳、指関節、硬質化の結晶色を描画。左右パンチ・鉄拳を引く予備動作・剣の二重軌跡を描き直した。

### 選択画面

シンプルな図形の立ち絵を廃止し、双剣を交差する構図、背後の巨人、ワイヤー、陰影付き装備、目・髪・表情を持つ独自SVGへ差し替えた。巨人形態のHUDポートレートも専用の顔・筋肉へ切り替える。原作の画像や音声を取り込んでいない。

人間とCPUに同じ変更を適用。巨人の大きい被弾判定、うなじ1.2倍、18秒制限、解除疲労は維持。既存17キャラの数値は変更しない。

## 検証

- `npm run build`、`npm run check`、`npm test`成功。89件成功、失敗/スキップ0。
- 既存エレン試験を新しいダメージ値に更新し、形態別フィニッシャー・発生後の後隙・変身時の無敵終了を追加検証。
- Chromium/p5 1.9.0のローカル検証ページで選択画面、人間、変身、巨人、鉄拳を描画。画面画像を確認し、実行時エラー0。初期実装と同様、外部CDN/Firebaseを除いたオフライン検証であり実オンライン試験ではない。
- 対既存17キャラ×2固定シード、左右交代、3残機、標準ステージ、3600フレームの模擬戦を同条件で比較。**6勝28敗→19勝15敗**。変身25→28回。前後の結果をeren-before-polish.json / eren-results.jsonへ保存。

少数シード・単一ステージのCPU対戦であり、対人バランスが完成したことを意味しない。力士・ゴム人間・炭治郎・承太郎には今回も負け越す。実機操作、通信遅延下の掴み、全ステージの巨体の視覚整合は引き続き未検証。

通信プロトコルは `SBO_NET_EREN_POLISH_V32` へ更新。旧版の技フレーム/性能と混在させないため、オンライン参加者は全員再読み込みして新しい部屋を作る。
