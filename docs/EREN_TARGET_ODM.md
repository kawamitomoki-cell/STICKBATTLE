# エレン：敵を狙う立体機動へ再設計

最新main `760bddf` から `feat/eren-target-odm` を作成。今回の「従来の調整を忘れ、攻撃を当てやすく爽快な操作にする」という依頼を優先する。

## 新しい操作

- **特殊**：近距離なら前後を斬る回転斬り。離れた敵がいればワイヤーを敵へ掛けて急襲する。
- **横特殊**：向けた方向の敵へ急襲。適当な敵がいなければ地形を使って移動する。
- **上特殊**：上方の敵を追って斬り上がる。敵がいなければ縦回転斬りで上昇。空中1回を維持。
- **急襲中にもう一度特殊**：回転斬りの追撃を予約。剣の間合いに入ってから発動する。
- **回転斬り命中→攻撃**：双剣へ連携。長押しは溜め、出し切りは吹き飛ばすフィニッシュ。
- **ジャンプ**：追尾を解除して離脱する。

相手の現在位置へ向きと上下速度を調整し、剣の間合いで減速する。ワイヤーの接続先は画面内の相手の胴体として表示し、飛行姿勢・ガス・残像を使用する。命中は移動後に既存の攻撃判定で確定し、ワイヤーを掛けただけではダメージを与えない。

追尾は最大340の範囲、最大30フレーム。速度は水平18・上下10以内。味方、消滅した敵、影分身、ステージ矩形の外に近い敵を追尾対象から除外し、ガスを消費する。被弾・拘束・ターゲット消滅・期限切れで中断する。相手の入力は参照せず、CPUと人間は同じ技と入力ルールを使う。回避・無敵・カウンターは引き続き有効。

通常特殊は近距離に敵がいる場合、その場の回転斬りを優先する。初撃で相手が少し離れても、追撃の先行入力は接近完了まで待ち、早すぎる空振りを防ぐ。巨人の技とジャンプ力は維持。

## 検証と限界

- ビルド・生成HTML整合性・全142件の自動テスト成功。動く敵と空中の敵への実命中、追撃予約、味方除外、消滅・被弾解除、追尾状態の制限付き復元を追加検証した。
- ChromiumのPC・スマホ相当の実入力で、約290離れた敵へ特殊で接近して14ダメージを当て、次の特殊で回転斬りへ移り追加ダメージが入ることを確認。実行時エラー0。Firebaseを使わないローカル描画・操作試験であり、実オンラインの成功とは区別する。
- 模擬対戦と1/7 CPU負荷試験の結果は `scripts/benchmarks/eren-hunt-results.json` と `eren-hunt-stress-results.json`。
- 実オンラインでの遅延・再接続、全ステージの崖際での追尾、実スマホ／ゲームパッド、対人バランスと爽快感の最終評価は未検証。回避した敵に必ず当たる、全地形で自滅しない、といった保証はしない。
- 接近先が不利な場所の場合はジャンプで追尾を切る判断が必要。CPUの複雑な追撃連携専用プランは今後の課題。

プロトコルは `SBO_NET_EREN_HUNT_V40`。公開後は全員再読み込み・新規ルームが必要。
