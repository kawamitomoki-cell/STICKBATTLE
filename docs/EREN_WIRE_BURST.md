# エレン：ワイヤー加速と巨人ジャンプ

最新main `0c4f423` から `feat/eren-wire-burst` を作成。爽快感を重視した追加調整。

- 上特殊にも実在する足場へのワイヤーを追加。ガス噴射・残像を表示し、出始めだけ短く加速して縦回転斬りへつなぐ。通常の上昇速度7.5→9、ワイヤー接続時の初動は最大9.5に制限。持続的な牽引による暴走上昇は行わない。空中1回制限を維持。
- 横特殊は最高速度14→16、牽引加速1.25→1.8、発射時に方向へ5の初速を加える。到達後の減速、足場の内側への接続、接続42フレーム、ガス消費と再接続制限は維持。
- 巨人のジャンプ倍率.78→1.08。標準地上からの上昇量は約74→145.2となり、110高い左右の足場へ移れる。通常の人間ジャンプ、攻撃ダメージ、18秒・硬質化は変更しない。
- 横回転斬り→攻撃／溜めの連携、出し切り18ダメージを維持。
