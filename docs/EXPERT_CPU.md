# 最強CPUの追加強化

## 変更

公開版 `9d66270` を基準に、最強の判断周期を4→2フレームへ変更。観測の遅延8フレームは維持し、操作の先読み・専用能力補正は追加していない。下位難易度の反応時間設定は維持するが共通の技選択・安全対策は全難易度に適用される。

- 遅延観測の位置を公開された速度から補間し、予測中の落下が実際の足場を貫通しないようにした。
- 通常/溜めの射程・発生見積りに長武器、狂戦士、フォームの補正を加えた。常に50フレーム待つ最大溜めだけでなく約14フレームの短い溜めを選べる。最大溜めは大きな隙に限定。
- ナルトの螺旋丸、承太郎のスターフィンガー、炭治郎・五条・ゴム人間の横特殊、悟空のかめはめ波、五条の茈を評価候補へ追加。CPUは従来と同じ方向入力・長押しで使用する。
- 硬直中/被弾中の敵へ距離を詰める。攻撃不能な距離での待機を減らした。
- 敵の向き、発生までの残り時間を考慮して防御。回避先の着地点が崖外になる場合は逆方向へ、両側とも危険なら回避しない。
- 飛び道具の認識距離を伸ばした。反応時間を満たしてから一部の遠隔技の溜めを早めに離し、次の防御を可能にする。弓は近距離単発/遠距離5本を優先。

## 残課題

弓使いは依然として旧版に負け越す。力士も同率。弓の被弾後の復帰、発射と防御の両立をさらに調整する余地がある。悟空同士は強化中の無敵や地形で時間切れが残る。
全方向技・変身/武器の正確な副作用なしの性能生成、固有コンボはまだ完全ではない。推定ダメージと射程の誤差は残る。実機・対人の体感評価、オンライン通信を含む性能測定は未実施。ゲームルールやキャラ性能を変えずに強化しており、「絶対最強」を証明したものではない。
